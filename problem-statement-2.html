AgriPulse: Satellite Based Land Use Classification

PS-02 · Track 2

Core Question

How can satellite imagery be used to automatically understand how land is being used across different regions?

The Problem

Governments, environmental planners, and researchers need an up-to-date understanding of how land is being used across different regions.

Manually analyzing large amounts of satellite imagery is difficult and time-consuming. Satellite-based land-use classification can help identify and map different types of land automatically.

What You Need to Build

AgriPulse is a satellite-image classification system built using Sentinel-2 imagery that should:

  • Classify satellite images into different land-use/land-cover categories
  • Visualize and map the classified land-use patterns
  • Provide insights or summaries based on the classification results

Bonus Features (Optional)

  • Interactive map/dashboard
  • Confidence score for predictions
  • Comparison of land-use patterns across regions
  • Change detection using additional satellite imagery
